把聊天记录全塞给 Agent，它就有记忆了吗？不一定。它只是能看到刚才的对话。聊天历史只是当前会话的 Context，不是一套完整的 Memory 系统。

换一个 Thread，或者 Context 被裁剪，历史信息就可能消失。这不是记忆故障，而是没有设计好 Memory 的边界。

工程上至少分三层：当前任务状态、线程内短期记忆、跨会话长期记忆。

比如用户说：我的项目都用 TypeScript。重放聊天历史，要带上一百多条消息，还会占用 Context Window。Memory 只需要保存一条结构化的用户喜好。

下次执行任务时，Agent 按用户 ID 检索，需要时再把这条用户喜好放进 Context，而不是每次重放整段聊天。

记住：聊天历史是原料；Agent Memory，才是管理写入、检索和删除的系统。
